# Bank Transaction Customer Segmentation & Cluster Classification

A machine learning project that explores bank transaction data, groups customers based on transaction-related characteristics using **K-Means clustering**, and evaluates classification algorithms to predict the generated cluster labels.

## Project Overview

This project applies unsupervised learning to discover customer groups from bank transaction data. After clustering, the generated cluster labels are used as targets in a supervised classification experiment.

## Project Workflow

1. **Exploratory Data Analysis (EDA)**
   - Inspect dataset structure, data types, descriptive statistics, and distributions.
   - Explore numerical and categorical features through visualizations and correlation analysis.

2. **Data Preprocessing**
   - Check missing values and duplicate records.
   - Convert transaction date columns to datetime.
   - Remove selected identifier and unused columns.
   - Calculate `DayFromTransaction` from transaction date information.
   - Handle numerical outliers using the IQR method.
   - Encode categorical features and standardize numerical features.

3. **K-Means Clustering**
   - Determine the number of clusters using the Elbow Method.
   - Fit K-Means and assign cluster labels.
   - Evaluate clustering with the Silhouette Score.
   - Apply feature selection (RFE) and compare clustering performance.
   - Visualize clusters and analyze their characteristics.

4. **Cluster Interpretation**
   - Examine customer age, account balance, transaction channel, transaction type, and location across clusters.
   - Interpret each cluster based on its dominant characteristics.

5. **Cluster Classification**
   - Load the dataset containing the generated cluster labels.
   - Split the data into training and testing sets (80:20).
   - Train and compare K-Nearest Neighbors (KNN), Decision Tree, Random Forest, Support Vector Machine (SVM), and Gaussian Naive Bayes.
   - Evaluate the models using Accuracy, Precision, Recall, F1-Score, and confusion matrices.

## Dataset

The project uses bank transaction data containing **2,512 records** and **16 columns** in the original dataset. The analysis uses transaction and customer attributes, including:

- `TransactionAmount`
- `CustomerAge`
- `TransactionDuration`
- `AccountBalance`
- `TransactionType`
- `Location`
- `Channel`
- `CustomerOccupation`
- Transaction date information

The clustering dataset contains selected features and a generated `Cluster` label.

## Important Note on Classification Results

The classification target is the **cluster label generated by K-Means**, not an independently collected customer category. Because the classifier uses features related to those used to create the clusters, very high classification scores—including 100%—do not necessarily mean the model can predict real-world customer behavior with perfect accuracy. They show how well the classifier reproduces the generated cluster assignments from the available features.
